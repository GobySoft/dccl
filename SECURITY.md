# Security Policy

## Supported Versions

Security updates are provided for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 4.y.z   | :white_check_mark: |
| 3.y.z   | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

Please report any vulnerabilities by using [GitHub's Private Vulnerability Reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/privately-reporting-a-security-vulnerability#privately-reporting-a-security-vulnerability).

If you've been unable to find a way to report it, or have received no response after repeated attempts, please email security@gobysoft.org.
